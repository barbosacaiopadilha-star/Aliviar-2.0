# Base de Conhecimento do ACE

Reservado para a base de conhecimento factual que os protocolos do ACE podem consultar (ex.: conteúdo institucional aprovado, respostas padronizadas a perguntas frequentes de clientes, glossário de apoio). Nenhum conteúdo foi definido ainda.

Nenhum protocolo deve presumir a existência de conteúdo aqui antes que ele seja adicionado e versionado explicitamente.

Também guarda material de apoio para quem trabalha no Método (não consultado pelos protocolos em si) — ex.: [`golden-set-testing.md`](golden-set-testing.md), sobre como validar em runtime, contra o modelo real, que a saída de um protocolo continua obedecendo às regras da sua `specification.md` (Kernel, seção 4).
