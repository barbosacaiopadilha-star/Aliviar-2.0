# 11 · Visualizações

A Rodada 2 propôs **nove oportunidades, nenhuma implementada**. Apliquei a
cada uma o teste: **que texto ou esforço isto substitui?** Se a resposta for
*"nenhum, seria adicional"*, não entra.

**Cinco entram. Quatro não.**

## Aprovadas

### V-C1 · Estado das seis perguntas da Mesa — **já existe**

A trilha certificada **é** esta visualização. **Nada a fazer** — registrada para
que ninguém a construa de novo.

### V-C2 · Contadores da Rede → **régua, não gráfico**

| | |
|---|---|
| **usuário** | Curador |
| **objetivo** | saber, sem contar, quantos profissionais faltam declarar |
| **origem** | contadores que a Mesa já calcula |
| **por que melhor que texto** | substitui *"Sem declaração 4 · Área compatível 0 · Já avaliado 0 · Pendente 0"* lido a cada volta — e **resolve C4**, o duplo vocabulário |
| **tipo** | régua de marcas por estado, **sem eixo, sem proporção** |
| **mobile** | quebra em duas linhas |
| **acessibilidade** | texto equivalente obrigatório |
| **risco** | ⚠️ parecer progresso avaliativo — **mitigação: contagem por estado, nunca barra proporcional** |

### V-C4 · Fila de Curadorias → **agrupamento por ato devido**

Substitui a leitura caso a caso. **⚠️ Não certificar sem os 5–10 casos
simultâneos** (§05.1, B2-4).

### V-P1 · A jornada → **linha do tempo única**

Substitui **duas** narrativas concorrentes (D2-1, P6). **É a visualização de
maior valor para a paciente**, e ela já existe duas vezes — o trabalho é
**consolidar**, não criar.

**Proibido:** percentual de conclusão. *"3 de 7 etapas"* vira nota mental de
progresso, e Curadoria não é barra de carregamento.

### V-P2 · Comparação dos três caminhos → **matriz editorial**

Substitui alternar abas e memorizar (P4). Detalhe em [§04.1](04_EXPERIENCIA_DO_PACIENTE.md).

**Risco máximo de interpretação.** Guardas: ordem **de apresentação**, dita ·
lacuna como lacuna · **sem** ranking, estrela, nota, score, percentual, vencedor
ou ordenação por atributo.
